# 央国企制度与合规知识库

本项目面向咨询项目中的制度梳理、内控诊断和合规问答场景。用户上传国资监管文件、制度办法、内控手册或流程表后，系统通过四个 Agent 完成解析、知识抽取、检索问答和增量更新。

## 业务闭环

1. 文档解析：识别 PDF、Word、表格和扫描件，保留来源文件、页码和版本等元数据。
2. 知识抽取：抽取制度文件、条款、监管要求、责任部门、业务流程、风险和控制措施，并构建关系图谱。
3. 合规问答：同时检索向量库与知识图谱，回答审批条件、责任边界、适用范围和制度冲突问题，返回原文依据与置信度。
4. 增量更新：制度修订时只处理变化页面，更新条款、版本和生效日期，避免全量重建。
5. 合规预审：对采购金额执行确定性规则判断，输出审批路径、风险红线、制度依据和下一步动作。

## 演示数据

`uploads/央国企采购制度示例.txt` 是可直接上传的脱敏样例，覆盖制度编号、版本、生效日期、适用范围、审批阈值、职责分工和重大合规风险。

## 推荐演示问题

- 采购金额超过 100 万元需要哪些审批？
- 采购申请部门和采购管理部各自承担什么责任？
- 哪些行为会被认定为重大合规风险？

## 推荐演示顺序

1. 在“制度知识库”上传采购制度示例，展示条款与关系抽取结果。
2. 在“对话工作台”提出三个推荐问题，展示向量与图谱混合检索及原文引用。
3. 在“合规预审”分别输入 80 万、120 万和 500 万，比较审批路径变化。
4. 修改制度样例后通过 `/api/admin/update` 触发增量更新，说明版本管理和知识同步机制；Watchdog/Kafka 自动监听需要单独启动 worker。

## 项目边界

这是用于校招作品集的可运行原型，不替代法律意见或企业正式审批。生产部署仍需补充身份权限、敏感数据脱敏、审计日志、模型评测和人工复核机制。
